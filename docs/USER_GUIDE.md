# 使用手册

## 接收历史记录

使用 OTG 将仪器直接连接手机。打开应用，点击“连接血脂仪”，允许系统弹出的 USB 访问请求。顶部显示“已连接 · PFS-30A”后可以打印。

仪器关机时短按 M 进入历史记录，用 M / S 选择记录，短按电源键进入 TC 结果详情，再长按 M 打印。关机时长按 M 会进入清除记录流程，进入历史列表时请短按。

每次打印后，应用提示保存结果，列表自动刷新。重复的完整报告不会新增记录。重复编号但时间或数值不同的报告会单独保留。

## 查看记录和曲线

记录卡片依次显示 LDL、TC、TG、HDL 和 TC/HDL，比值不带单位。箭头来自仪器报告。

曲线默认显示最近 52 条，点之间等距。另可切换为全部记录按实际检测时间排列，或手机当前日期往前一年的记录按时间排列。下面的列表始终显示全部记录。

2.2“合格”和 1.8“优秀”是本项目用户指定的个人目标，单位为 mmol/L。非数值或其他单位的结果保留在列表中，曲线对应位置跳过。

## 本地存储和升级

所有报告保存在应用私有目录的 records.db。安装同包名、同签名的新版本时保留数据库。请使用覆盖安装，避免卸载重装或清除应用数据。

接收时保持应用打开。设备断开后，重新连接并点击连接按钮。手机重启或应用重启后可离线查看已保存的数据。

## 常见问题

- 未发现设备：检查 OTG 支持、数据线及仪器连接。
- USB 授权失败：重新点击连接，并允许访问。
- 没有新记录：确保在 TC 结果详情页长按 M，出现打印图标。
- 更新安装失败：检查签名是否与原版本一致，versionCode 是否递增。
